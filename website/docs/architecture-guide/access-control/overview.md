# Overview

This section contains the design content for Serendipity's access-control model — users, groups, and permissions for the core customer-engagement domain (Accounts and Contacts).

## Contents

- [Users, Groups, and Permissions Model for Accounts and Contacts](./users-groups-permissions-model.md) — the **design doc (proposal)**. The model (roles, ownership, assignment, teams, scope, operations), the token design, the enforcement approach, the data-model additions, and the open questions. This doc is a proposal; it has not been accepted as a decision yet. Once a decision is reached, the decision will be recorded as an ADR, and this doc will remain as the background and detail behind it.
